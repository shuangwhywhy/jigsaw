# jigsaw

一个在浏览器中运行的随机景深拼图游戏。打开 `index.html` 即可自动生成一幅写实彩色的风景图，并把它分割成 10~30 行、10~30 列的等大块，满足最小尺寸 20px。所有块带 1px 内描边，初始随机打乱且保证四向相邻不会与原图一致。

## 玩法
- 打乱后的区块可以拖动到任意区块上方实现交换，释放后会自动吸附到最近的格子。
- 拖动可能超出边界时，区块会按行/列取模换位，再与原位置的区块整体交换。
- 当任意两块恢复到原图的相邻关系（位置可变），它们之间的黑边会消失并融合成可共同拖动的 group。
- 全部区块回到原位后，黑边消失，本局结束，可点击「重新生成拼图」再来一局。

## 运行
直接在本地用浏览器打开仓库根目录下的 `index.html` 即可体验，无需额外依赖。

## 测试
安装 Node.js 18+ 后执行：

```bash
npm test
```

该命令会运行核心拼图逻辑的单元测试，验证网格邻接计算、切片尺寸和打乱算法确保不保留原始相邻关系。
